FINAL 23 — JASEB PERSISTENT BACKUP SCOPE

Auto Comment + Jaseb backup now preserves ONLY the persistent data needed to restore the service:
- Telegram account/session data
- Keywords + reply text
- Channel/discussion targets
- Jaseb text + interval + selected groups + enabled state

Excluded from both backup trigger signatures and backup payload for this tenant:
- logs
- sent history
- monitor counters/state
- sender runtime flags
- UI/meta/cache/temp/runtime data

Other tenant types keep their existing backup behavior.
